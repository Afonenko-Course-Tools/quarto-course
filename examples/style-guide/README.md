# Самостоятельные примеры руководства

Примеры используют штатные `html` и `revealjs` Quarto без фильтров Core,
Presentation, Navigation, темы БГУ и QRC. Это один маленький проект для
проверки разметки; он не заменяет шаблон совместного выпуска курса.
Локальные ссылки здесь относятся к одному проекту. Между отдельными частями
настоящего курса используются только QRC-ссылки.

Из этого каталога:

```sh
quarto render
quarto preview
```

| Исходник | Назначение |
| --- | --- |
| `java-before.qmd` | Намеренно перегруженный слайд для разбора |
| `java-after.qmd` | Прогноз, объяснение, перегрузка, сопоставление |
| `dense-comparison.qmd` | Плотная, но осмысленная сравнительная таблица |
| `java-dispatch.qmd` | Полное изложение и завершённый Java-пример |

Результаты находятся в `_output/`, не коммитятся. Java-блоки — текстовые
примеры, Quarto не компилирует и не исполняет их. Изображения в соседних
каталогах страниц — снимки фактического Reveal-рендера, используемые
[руководством](../../docs/authoring-style-guide.md). Обновляйте их при
изменении соответствующей композиции.

У примеров `show-notes: false`: `.notes` остаются в HTML и доступны в
Speaker View (`S`). Фрагменты заранее присутствуют в HTML.
Print View открывается через меню Reveal либо `?print-pdf`; PDF слайдов
отдельно не сохраняется в репозитории. Footer содержит обычные ссылки на
открытый репозиторий; это статически записанный путь каталога примеров,
не автоматический source map текущего QMD.
