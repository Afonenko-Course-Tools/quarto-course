# Пример курса

Quarto 1.10.18/1.11.5 и CUE 0.17.1.

Metadata задачи обновлена до текущего канонического контракта. Конфигурация
этого legacy примера пока требует миграции на [owner lifecycle](../../docs/owner-preflight.md)
с student/full профилями и последним owner-freeze hook; прямые render/preview
ниже больше не являются поддерживаемым способом сборки канонических exr и
возвращают SOURCE.OWNER_PREFLIGHT_REQUIRED. Они сохранены как точка миграции
существующего сценария tests/example.ts, а не как доказательство приёмки.

Из корня репозитория:

```sh
cd examples/course
quarto add ../..
quarto render
quarto preview
```

`quarto add ../..` копирует расширение из корня репозитория в этот пример. После изменения исходников расширения повторите команду. Установленные копии и результаты рендера исключены через `.gitignore`; QMD и авторские ресурсы остаются под контролем версий.
