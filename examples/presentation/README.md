# Абзацы, разделы и продолжения

Один исходник показывает нативные HTML и Reveal: YAML `title` задаёт лекцию,
`##` — раздел, `###` — слайд. Для Reveal `_quarto.yml` задаёт
`shift-heading-level-by: -1`, `slide-level: 2` и `navigation-mode: linear`.
В HTML уровни остаются исходными.

Разделы содержат вводный текст. Граница `---` создаёт продолжение без заголовка;
оно остаётся в группе текущего раздела. Повторные названия тематических слайдов
допустимы. Новый `##` начинает новую группу даже при повторном названии раздела.

`format.revealjs.css: prose.css` подключает обычный CSS Quarto: абзацы выровнены
по ширине, последняя строка слева; заголовки, код и вывод слева. `lang: ru`
задаёт русский язык документа для `hyphens: auto`. Фактическое наличие переносов
зависит от словаря браузера. Размеры шрифта и подсветка кода сохраняются.

Установите расширения из локального checkout, затем запустите сборку из корня
репозитория:

```fish
cd examples/presentation
quarto add ../.. --no-prompt
cd ../..
fish examples/presentation/render.fish
```

Получаются `examples/presentation/_output/index.html` и
`examples/presentation/_output/index-revealjs.html`. Пример использует
расширения из этого репозитория. В отдельном проекте установите целый выпуск
`quarto-course` штатной командой `quarto add`, затем скопируйте три исходных
файла `_quarto.yml`, `index.qmd` и `prose.css`.
