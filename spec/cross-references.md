# Публикация книги и слайдов

Учебная модель и издательская структура независимы. Course Core проверяет задания и занятия; Reference Catalog связывает HTML-объекты трёх самостоятельных проектов Quarto.

## Структура

Корневой проект имеет тип `website` и подключает `reference-catalog`. Подкаталоги `book`, `lectures` и `practice` содержат собственные `_quarto.yml`. В книге список документов определяется `book.chapters` и `book.appendices`; у слайдов — `project.render`. Произвольный обход всех QMD вместо выбора Quarto не применяется.

```yaml
project:
  type: website
  output-dir: _site
  render: []
filters: [reference-catalog]
reference-catalog:
  namespace: site
  home: book
  projects:
    book: {path: book, format: html}
    lectures: {path: lectures, format: revealjs}
    practice: {path: practice, format: revealjs}
```

`home` задаёт проект, размещаемый в корне публикации. Он должен иметь формат HTML и выдавать `index.html`. Его дерево вывода публикуется целиком; все внутренние пути сохраняются. Для этого проекта `mount` не задаётся. Корневой `render: []` оставляет рендер документов подпроектам; внешний index не создаётся.

Без `home` допускается обычная страница портала в корневом проекте. Подпроекты тогда размещаются в каталогах, определяемых `mount` либо namespace.

## Идентичность ссылок

`@book:fig-layout`, `@lectures:sec-memory` и `@practice:exr-clamp` задают namespace и явный ID. Номер и подпись определяет проект назначения. При переносе файла или изменении `output-file` ID сохраняется, а опубликованный URL пересчитывается.

Книга и слайды могут ссылаться друг на друга. Сначала каждый проект рендерится независимо, затем собираются все цели и разрешаются ссылки. Цикл ссылок не образует цикла исполнения. Предыдущий каталог не нужен.

## Проверки

Расширение проверяет наличие подпроектов, допустимые форматы, отсутствие пересечения исходников с output, уникальность целей, HTML-якоря, корректность штатных подписей и межпроектных ссылок. У объектов Revealjs должен существовать содержащий слайд с явным ID. Конфликт каталога слайдов с содержимым главной книги останавливает сборку.

Внутренние URL относительные, поэтому сайт переносим между локальным сервером, GitHub Pages под префиксом репозитория и отдельным доменом. Публикуется только итоговый output.

Нормативная форма конфигурации описана в `publication.cue`. Фактические файлы, HTML-якоря и коллизии проверяются Reference Catalog. Эта схема не включается в `#Course`: её правила не относятся к оцениванию заданий.
