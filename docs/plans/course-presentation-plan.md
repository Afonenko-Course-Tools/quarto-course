# Единая презентация и навигация

План Presentation и Navigation в репозитории `quarto-course`: одно содержание и один рендер, общие заметки, управление раскрытием, поиск и печать.

Общие решения, ограничения и порядок выпуска: [межрепозиторный план](../../../specs/course-change-plan.md). Перед изменением поведения — анализ актуальной архитектуры и необходимый рефакторинг. Поддерживается только актуальный авторский формат без обратной совместимости; публичные функции Quarto переиспользуются. Код, спецификации, README и примеры обновляются согласованно в соответствующем PR.

Проверки результата: переключение одного HTML без повторной сборки; неизменные порядок, ID и основное содержание слайдов; режим самостоятельного изучения при обычном открытии; аудиторный режим по явной ссылке; отсутствие сохранённого режима после перезагрузки; штатное окно заметок по `S`; переход к скрытому ответу; поведение открытой цели после переключения; поиск и обзор; печать и восстановление экрана.

Для общих заданий условия и устойчивые ID одинаковы. Отдельные контрольные материалы отсутствуют в студенческом списке файлов и входят в локальный full-site вместе с решениями и комментариями. Полный вариант курса не публикуется рядом со студенческим. Презентация ссылается на доступные общие условия; ссылки из публичных материалов на исключённые контрольные не разрешаются, а локальный full-каталог отражает свой состав файлов. Состав платформенного экспорта определяется полными исходными данными выбранной работы.

## Реализация на актуальной базе 6 октября

База `213a77c` (Core/Presentation/Navigation 2.1.1). Native Core уже использует текущие AST и outputs без повторных предварительных рендеров. Presentation оформляет ответы через Bootstrap для HTML и details для Reveal; разветвление lecture/study ещё меняет HTML. Navigation индексирует только слайды без общих notes.

Публичный API Reveal `configure({showNotes})` и `getSlideNotes()` уже предоставляет показ заметок рядом со слайдами и штатное окно S. Его используем вместо собственного движка заметок. Единственный экранный HTML содержит details, состояние режима живёт в странице и параметре ссылки `course-mode=lecture|study`. Корректность выбранного режима не зависит от student/full.
