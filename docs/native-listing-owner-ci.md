# Required installed native Listing checks

`tests/native-listing-owner.ts` is a small native fixture: five selected static
book inputs, four stock table declarations, and three listed topics. Its scope
is separate from the original course. The index has the three original
`title,categories` difficulty/semester declarations. The unnumbered text part
has the `title,semester,categories` declaration with page size 10 and three
rows. Topic Source headings retain ordinary IDs and includes.

The harness archives every candidate extension file, installs that archive with
the actual `quarto add`, and compares the complete installed path/SHA/byte map.
Each student/full owner prepares the mandatory two-profile capture and Header
identity matrix. The Listing-emitting inputs retain their distinct capture,
identity and current-render reader/witness evidence. Static Markdown does not
claim Core's Jupyter-only whole-input replay.

Only an awaited real CLI zero precedes `finishOwner` and the public current
accessor. A completed owner must account for all five current writers, the
finite auxiliary `listings.json`, both stock Listing assets and the exact
address receipt bound by the resource index. Raw Source and private reader,
constructor, receipt and stock service bytes remain denied.

Each completed owner runs 23 current/refusal checks: 12 byte/deletion mutations,
a renamed address receipt, five raw selections and five renamed private output
aliases. Exact restoration returns the same invocation and index without another
native render. The two previous publication maps stay unchanged. Separate finite
preparations reject an unsupported field and a destination under a
student-closed ancestor. The latter must retain the named destination refusal; a
generic capture failure alone cannot pass the test.

The required workflow runs the reviewed stable 1.10.18 and the actual latest
prerelease. Its resolver currently supports the independently reviewed
prerelease 1.11.5, so a new unknown prerelease fails the exact-version gate. The
original seven required jobs retain their existing definitions. Two new native
jobs and one aggregate require complete original logs and every artifact
path/length/SHA. A failed render, skipped channel, missing proof, fallback or
synthetic owner receipt cannot satisfy this gate.

For an authorized local native run, provide the absolute canonical actual CLI
and a fresh absolute output directory:

```sh
QUARTO=/absolute/quarto/bin/quarto \
NATIVE_LISTING_EXPECTED_QUARTO=1.10.18 \
NATIVE_LISTING_TEST_OUTPUT=/absolute/fresh-evidence \
/absolute/quarto/bin/quarto run tests/native-listing-owner.ts
```
