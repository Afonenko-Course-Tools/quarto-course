## T-02 / T-03: нативная презентация и выпуск

Настройка использует публичные API Quarto: `lang: ru`, `format.revealjs.css`, `shift-heading-level-by: -1`, `slide-level: 2`, `navigation-mode: linear`. Обычный абзац выравнивается по ширине, последняя строка — слева; заголовки, код и вывод — слева. `hyphens: auto` использует словарь браузера, поэтому проверены язык и вычисленные браузером стили, а конкретное разбиение слов во всех браузерах не обещается.

YAML `title` задаёт лекцию, `##` — раздел, `###` — тематический слайд. Физическая граница `---` создаёт продолжение без нового заголовка. Существующая Navigation поддерживает эту модель без изменения исполняемого кода. Новый YAML-ключ Presentation, общий исполняемый слой и слой обратной совместимости не добавлены.
