# Core / Presentation / Navigation 9.1.2

Кандидат сокращает повторную обработку документов в обеих ветках A1: standalone `readProjectContexts` и `operation.withProjectContexts`. Для каждого input остаётся настоящий native `quarto inspect`, но временный технический проект выбирает только этот input. Исходные конфигурации и документы не меняются; origins вычисляются по исходным scalar ranges до преобразования временной конфигурации.

Массивы `project.render` Quarto объединяет. Поэтому временная копия снимает исходный selector, сохраняя остальные значения, включая metadata через YAML alias. Проверка сравнивает metadata с настоящим native inspect выбранных исходных документов; служебное загрязнение alias старым профилем ALLN не сохраняется. Наследование, локальные параметры, профили и смешанные html/revealjs проверяются отдельно.

Проверки одного контекста используют его зависимости вместо растущего общего множества соседних проектов. Общие проверки на границах batch, SAME S, проверка перед и после чтения, lifetime и запрет DTO authority сохраняются.

Тема course-theme-html остаётся 1.0.0. Общий аудит inspect во всех расширениях, новый сравнительный замер и exact hosted CI ещё обязательны. Этот исходник не подтверждает время полной Java-сборки, actual assignment/P, экспорт 135 задач или публикацию курса. Пустой устаревший native `*_files/mediabag` пока требует отдельного адресного решения; рекурсивное удаление и широкое исключение путей не добавлены.
