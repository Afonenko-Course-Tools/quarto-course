# Core / Presentation / Navigation 9.1.0

Кандидат выпуска объединяет публичную композицию навигации, режим лекции и поддержку совместимых версий Quarto. Необязательная HTML-тема `course-theme-html` сохраняет собственную версию **1.0.0**. Исторические выпуски не изменяются; публикация и hosted CI этого точного commit проверяются отдельно.

`composeNavigation` включается через `course-navigation.enabled` и сохраняет штатные элементы navbar Quarto. Режим лекции доступен через Alt+Shift+A и мобильные элементы управления; он не меняет учебные данные. HTML-тема подключается явно. Vendored HTML parser и его лицензии поставляются вместе с Navigation.

У `.course-block` больше нет стандартных боковой рамки и внутреннего отступа. Внешний вертикальный отступ, метаданные, роли, раскрытие решения, семантические ID и ссылки сохраняются.

Минимальная версия программы Quarto — **1.11.5**. В исполняемом каноне SemVer проверяется при получении настоящего owner; некорректные версии и версии ниже минимума отвергаются. В owner witness сохраняется фактическая версия программы. A1 по-прежнему требует точного совпадения версий исходного и временного контекстов. Поле публичной identity `runtime: quarto-1.11.5` остаётся идентификатором прежнего технического ABI, а не отчётом о версии запущенной программы; его контракт и hash domains не меняются.

CI запускает канонический набор отдельно на Quarto 1.11.5 и 1.11.6. Локальные адресные проверки покрывают настоящие native операции, A1, ресурсы, cached preview и UI. Они не заменяют exact hosted CI, независимую рецензию, опубликованный immutable release, квалификацию assignment/P и проверку полного состава курсов. Состав Java/SP и их текущие pins этим выпуском не изменяются.
