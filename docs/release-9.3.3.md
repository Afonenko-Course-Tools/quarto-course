# Core 9.3.3 — кандидат

При подготовке самостоятельного публичного тела Core исключает два служебных
Quarto 1.11.5 markdown-envelope для HTML metadata и навигации. Их полная
штатная структура проверяется до исключения. Копии заголовка для social metadata
больше не становятся повторными целями во введении работы. Обычные авторские
hidden-блоки, действительные ID, ссылки и строгий отказ настоящих дубликатов
сохраняются. Raw/full исходный AST не изменяется этой публичной проекцией.

Исправление проверено на сохранённых закрытых captures Java/SP без нового
render/inspect. Полный внешний экспорт C после интеграции и независимая
техническая рецензия остаются отдельными обязательными проверками. Это описание
кандидата, а не утверждение опубликованного тега или готовности курса.
